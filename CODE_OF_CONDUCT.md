# Community code of conduct

Be respectful, specific, and helpful. Critique code and ideas without attacking people. Welcome learners with different backgrounds and experience. Do not harass, discriminate, threaten, disclose private information, or encourage unauthorized testing.

Keep issues and pull requests focused on HexDojo. Report ordinary problems with reproducible steps. Handle security findings through private vulnerability reporting, never public exploit reports.

Maintainers may edit or remove harmful material, close disruptive discussions, and restrict participation for repeated or serious violations. Maintainers are accountable to the same standards. Report conduct issues privately to the repository maintainer through a contact channel they explicitly provide; do not post private allegations or personal information publicly.
